## 1) Мета:
Засвоєння теоретичного матеріалу та набуття практичних навичок розв'язання задачі пошуку заданої категорії елементів за допомогою різних алгоритмів методу двійкового пошуку у двовимірних масивах.
## 2) Завдання: 
### Умова:
Написати програму розв'язання задачі пошуку (за варіантом) у двовимірному масиві (матриці) методом двійкового пошуку. Конкретний алгоритм двійкового пошуку (№1 або №2) задається варіантом завдання.
Розміри матриці m та n взяти самостійно в межах від 7 до 10.
При тестуванні програми підбирати такі вхідні набори значень матриці, щоб можна було легко відстежити коректність виконання пошуку, і щоб ця коректність була протестована для всіх можливих випадків. З метою тестування дозволяється використовувати матриці меншого розміру.
### Варіант 10:
| № | Завдання |
|---|---|
| 10 | Задано матрицю дійсних чисел A[m,n]. Визначити присутність серед усіх елементів матриці заданого дійсного числа X і його місцезнаходження (координати) методом двійкового пошуку (Алгоритм №2), якщо елементи кожного рядка окремо впорядковані за незменшенням. |
## 3) Код:
```
#include <stdio.h>

#define N 7
#define M 8

int main()
{
    float arr[N][M];
    float x;
    int k, i, j;
    int match_count = 0;

    printf("Вкажіть шукане дійсне число x: ");
    scanf("%f", &x);

    for (i = 0; i < N; i++)
    {
        printf("Заповніть %d-й рядок (%d чисел за незменшенням): ", i + 1, M);
        for (j = 0; j < M; j++)
        {
            scanf("%f", &arr[i][j]);
        }
    }

    printf("\nОтримана матриця має вигляд:\n");
    for (i = 0; i < N; i++)
    {
        for (j = 0; j < M; j++)
        {
            printf("%7.2f ", arr[i][j]);
        }
        printf("\n");
    }
    printf("\n");

    for (k = 0; k < N; k++)
    {
        int l = 0;
        int r = M - 1;
        int found_I = -1;

        while (l <= r)
        {
            int I = l + (r - l) / 2; 

            if (arr[k][I] == x)
            {
                found_I = I; 
                r = I - 1; 
            }
            else if (arr[k][I] < x)
            {
                l = I + 1;
            }
            else
            {
                r = I - 1;
            }
        }

        if (found_I != -1)
        {
            printf("Елемент присутній за координатами: [%d][%d]\n", k, found_I);
            match_count++;
        }
    }

    if (match_count == 0)
    {
        printf("Шукане число відсутнє у масиві.\n");
    }

    return 0;
}
```
